# frontend

Next.js 14 (App Router) + TypeScript + Tailwind + shadcn/ui.

## Stack

- Next.js 14.2 + React 18
- TanStack Query + Zustand
- D3 + Recharts + react-flow (visualization)
- Shiki (code highlighting), Mermaid (diagrams)
- Playwright (E2E)

## Dev

```bash
cd frontend
pnpm install
pnpm dev
```

Open <http://localhost:3000>.
