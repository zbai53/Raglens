# Frontend scaffolding — run once

Next.js scaffolding is generated by `create-next-app`, not hand-written.
Run these commands **from the `frontend/` directory** to populate this folder.

## 1. Scaffold Next.js 14 (App Router + TS + Tailwind)

```bash
cd frontend
# In-place scaffold. Pin Next 14 for W1 (React 18, stable ecosystem).
pnpm create next-app@14.2 . \
  --typescript --tailwind --app --src-dir --import-alias "@/*" --no-eslint --use-pnpm
```

Answer the interactive prompts:
- "Would you like to use ESLint?" → **No** (we run ruff-style linting via biome later)
- "Would you like to customize the default import alias?" → keep `@/*`
- "Ok to proceed?" → **yes** (overwrites Dockerfile/.dockerignore is fine — we'll restore them below)

If create-next-app overwrites `Dockerfile` / `.dockerignore` / `SETUP.md`, `git checkout` them from git.

## 2. Enable standalone output (required by Dockerfile)

Edit the generated `next.config.mjs`:

```js
/** @type {import('next').NextConfig} */
const nextConfig = {
  output: 'standalone',
  reactStrictMode: true,
};

export default nextConfig;
```

## 3. Install runtime deps

```bash
pnpm add \
  zustand \
  @tanstack/react-query \
  @tanstack/react-query-devtools \
  axios \
  d3 \
  reactflow \
  recharts \
  shiki \
  mermaid \
  clsx \
  tailwind-merge \
  lucide-react

pnpm add -D \
  @types/d3 \
  @playwright/test
```

## 4. Init shadcn/ui (Slate theme)

```bash
pnpm dlx shadcn@latest init --defaults
# Then, as pages need them:
pnpm dlx shadcn@latest add button card dialog input label toast
```

## 5. Verify

```bash
pnpm dev              # http://localhost:3000 shows Next.js welcome
pnpm build            # produces .next/standalone
```

## 6. Then rebuild the docker image

From repo root:
```bash
docker compose build frontend
docker compose up -d frontend
curl -sf http://localhost:3000 | head -5
```

---

**Once this is done, delete this SETUP.md** — it's a one-time bootstrap doc.
